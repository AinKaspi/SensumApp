### SensumApp Root (/SensumApp)

_Описание ключевых файлов и папок в корневой директории проекта SensumApp (не путать с корнем репозитория)._

*   `/Users/inga/Desktop/SensumApp/SensumApp`:
    *   `AppDelegate.swift`: Стандартный делегат приложения iOS. Отвечает за жизненный цикл приложения и начальную настройку (например, Firebase, Push-уведомления).
    *   `Assets.xcassets/`: Каталог ассетов Xcode. Содержит иконки, изображения, цвета и другие ресурсы приложения.
    *   `Base.lproj/`: Базовая папка локализации. Обычно содержит `Main.storyboard` или `LaunchScreen.storyboard`, если они используются. (Нужно проверить содержимое).
    *   `Coordinator.swift`: (Предположительно) Протокол или базовый класс для координаторов навигации в приложении, реализующий паттерн Coordinator.
    *   `GoogleService-Info.plist`: Конфигурационный файл для интеграции с сервисами Google (Firebase). Содержит ключи API и другие настройки.
    *   `Info.plist`: Основной информационный файл приложения. Содержит метаданные, такие как идентификатор бандла, номер версии, разрешения (permissions), поддерживаемые ориентации и т.д.
    *   `SceneDelegate.swift`: Делегат сцены (для iOS 13+). Управляет жизненным циклом UI сцен (например, `UIWindowScene`), включая создание окна (`window`), настройку корневого ViewController и обработку событий сцены. Вероятно, здесь инициализируется главный координатор приложения (`AppCoordinator`).
    *   `pose_landmarker_full.task`: Файл модели MediaPipe Pose Landmarker. Используется для анализа поз в реальном времени (например, в фиче Leveling).
