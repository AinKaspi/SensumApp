## Core/Services

*   `/Users/inga/Desktop/SensumApp/Core/Services/AuthService.swift`: Управляет аутентификацией пользователя (Email/Password, Google Sign-In) через Firebase Auth. Публикует статус аутентификации (`authenticationState`) через Combine. Содержит методы для регистрации, входа, выхода, проверки статуса. Определяет `AuthServiceProtocol`.
*   `/Users/inga/Desktop/SensumApp/Core/Services/FollowService.swift`: Управляет системой подписок. Использует Firestore batch writes для атомарной подписки/отписки, обновляя подколлекции `followers`/`following` и счетчики. Содержит методы для проверки статуса подписки и получения списков ID подписчиков/подписок. Зависит от `AuthService`. Определяет `FollowServiceProtocol`.
*   `/Users/inga/Desktop/SensumApp/Core/Services/MessagingService.swift`: Отвечает за логику чатов (получение списков, сообщений, отправка, создание). Определяет `MessagingServiceProtocol`. **Большинство методов пока являются заглушками (Not Implemented).** Работает с коллекциями `chats` и подколлекциями `messages` в Firestore. Зависит от `AuthService`.
*   `/Users/inga/Desktop/SensumApp/Core/Services/NotificationService.swift`: Отвечает за работу с уведомлениями пользователя (получение, отметка прочитанными). Определяет `NotificationServiceProtocol`. **Методы пока являются заглушками (Not Implemented).** Работает с коллекцией `notifications` Firestore. Зависит от `AuthService`.
*   `/Users/inga/Desktop/SensumApp/Core/Services/PostService.swift`: Центральный сервис для управления постами, лайками, комментариями. Включает: создание поста (с mediaItems, aspect ratio, денормализацией автора), получение постов (пользователя/ленты, с пагинацией), лайк/анлайк, удаление, добавление/прослушивание комментариев. Использует Firestore (`posts` коллекция, подколлекции), `Codable`. Зависит от `AuthService`, `UserProfileService`. Определяет `PostServiceProtocol`.
*   `/Users/inga/Desktop/SensumApp/Core/Services/ProgramService.swift`: Управляет программами тренировок (CRUD). Определяет `ProgramServiceProtocol`. **Методы пока являются заглушками (Not Implemented).** Работает с коллекцией `trainingPrograms` Firestore. Зависит от `AuthService` для проверки авторства.
*   `/Users/inga/Desktop/SensumApp/Core/Services/ProgressService.swift`: Управляет RPG-прогрессом пользователя (XP, уровень, ранг, атрибуты). Основной метод `addXP` обрабатывает начисление опыта, бонусы, повышения уровня/ранга, прирост атрибутов. Использует Firestore (`progress` коллекция). Содержит вспомогательные расчетные методы. **Выглядит полностью реализованным.** Определяет `ProgressServiceProtocol`.
*   `/Users/inga/Desktop/SensumApp/Core/Services/StorageService.swift`: Управляет загрузкой/удалением файлов (изображений) в Firebase Storage. Содержит методы для загрузки общих изображений, изображений постов (`post_images`) и аватаров (`avatars`), а также для удаления файлов по URL. Конвертирует UIImage в JPEG. **Выглядит полностью реализованным.** Определяет `StorageServiceProtocol`.
*   `/Users/inga/Desktop/SensumApp/Core/Services/UserProfileService.swift`: Управляет профилями пользователей в Firestore (создание, получение, обновление). Использует коллекцию `users` и `Codable` для модели `User`. **Основные функции реализованы.** Определяет `UserProfileServiceProtocol`.
