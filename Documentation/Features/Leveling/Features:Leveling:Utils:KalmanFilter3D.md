Файл: Features/Leveling/Utils/KalmanFilter3D.swift
Название файла: KalmanFilter3D.swift
Назначение файла: Реализация 3D фильтра Калмана.
Описание: Предоставляет фильтр Калмана для сглаживания 3D-координат (например, точек позы). Учитывает шум процесса и шум измерения (который может зависеть от видимости точки). Имеет методы predict и update.
Содержит: Класс KalmanFilter3D, методы predict, update, свойства для состояния фильтра.
Технологии: simd (для векторной математики).
Путь: Используется ExerciseExecutionViewModel для сглаживания worldLandmarks.
