Папка: Features/Notifications
Название папки: Notifications
Назначение папки: Отображение уведомлений для пользователя.
Описание: Заглушка для фичи уведомлений. Содержит координатор и ViewController-заглушку. Не содержит ViewModel или логики загрузки/отображения уведомлений ([P2.NOT.4]).
Содержит: Папку Coordinators/, файл NotificationsViewController.swift.
Технологии: UIKit.
Путь: AppCoordinator.showNotifications() -> NotificationsCoordinator.start() -> NotificationsViewController.
