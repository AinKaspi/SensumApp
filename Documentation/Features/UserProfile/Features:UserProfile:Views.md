Название файла: PostGridCell.swift
Назначение файла: Ячейка для отображения превью поста в сетке (UserProfileFeedViewController).
Описание: Простая ячейка UICollectionViewCell, содержащая UIImageView на весь размер ячейки. Метод configure(with:) загружает изображение поста с помощью Kingfisher.
Содержит: Класс PostGridCell, UIImageView, метод configure.
Технологии: UIKit, Kingfisher.
Путь: Используется UserProfileFeedViewController в collectionView(_:cellForItemAt:).
